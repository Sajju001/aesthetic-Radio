# Aesthetic Radio

A nostalgic, retro-inspired ambient radio web experience designed around the atmosphere of a vintage Pakistani office.

## Features

* Responsive single-page design
* Retro Pakistani office visual theme
* Urdu-inspired vintage typography and aesthetics
* Full-screen cinematic background
* Frosted glassmorphism UI
* Live 12-hour digital clock
* Dynamic online listener counter
* Spotify and YouTube Music buttons
* Playlist modal
* Radio songs queue modal
* PWA installation instructions
* WhatsApp community CTA
* Floating glass music player
* Play / Pause controls
* Previous / Next track controls
* Interactive seekbar
* Live playback timer
* Volume control
* Animated spinning album artwork
* Vintage radio hiss/crackle effect using Web Audio API
* Autoplay-unblocking "Tap to play music" overlay
* Mobile-friendly responsive layout

## Music Player

## Running Locally

Simply open `index.html` in a modern web browser.

For the best experience, run the project through a local development server because some browser features, including PWA functionality and certain audio APIs, may require HTTP/HTTPS.

## PWA

The application is designed to support installation as a Progressive Web App.

Users can install **Aesthetic Radio** directly on supported desktop and mobile devices from the browser's installation option.

## Browser Compatibility

Recommended browsers:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

A modern browser with Web Audio API support is recommended for the complete radio experience.
